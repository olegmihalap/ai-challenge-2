## Steps 
 Publish → RSVP → Ticket → Check-in. This should be a usage guide, not a copy of the requirements.


### Host steps
 1. Click on Sign up button to create a new user or sign in with credentials(host creds)
 2. For a new account click on user icon on top right and select Become a host button
 3. Fill the form to become a host
 4. Click on My events on top nav bar
 5. Click on Create event
 6. Fill the form and create new event
 7. In Host dashboard you can manage your events
 8. Check attendee steps to create/use attendee account

### Host steps to check in user
1. Open Host Dashboard
2. Click to check in menu item on the left menu
3. Select event from your event list
4. Select manual check in(or by qr)
5. Copy/paste ticket code from attendee acount. it uplaced under QR code in attendee ticket
6. User will be check in

### Host CSV
1. Click on My events in Host dashboard
2. Click on three dots icon at the end of event list and select Export RSVPs CSV

### Gallery Moderation
1. Open event page with attendee account.
2. Scroll down a bit and click on Upload photos button
3. Upload photo
4. Switch to host account.
5. Open Gallery moderation page in Host dashboard
6. You'll see uploaded photo with accept/regect options.

### Report event
1. User attendee account. On event page under View ticket , Cancel RSVP you'l see Report this event button
2. In host account you can check reports page in Host Dashboard


### Attendee steps
 1. Click on Sign up button to create a new user or sign in with credentials(attendee creds)
 2. Fill the form to create a new user
 3. Click on Explore tab on top nav bar and select event
 4. Click on RSVP - Get Ticket to attend in event and get ticket
 5. Then you can click Tickets tab to check your tickets for events
