# Airport ATC — runnable package

Install, build, and run the MCP server from **this directory** (`task-4/code/`).

```bash
npm install
npm run build
node dist/index.js
```

Full documentation, environment variable reference, and MCP wiring examples: [../README.md](../README.md). Copy `.env.example` to `.env` in this directory if you do not use the root `task-4/.env`.
